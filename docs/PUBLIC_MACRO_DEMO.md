# Public macro-data demo notes

A practical extension can use the public `statsmodels` macrodata sample (quarterly US macro series) as a transparent example dataset. The values in common packaged macrodata are not a real-time-vintage database.

When illustrating release delays, keep any `available_at` schedule explicitly labelled as an **assumption for demonstration** unless an authoritative historical release/vintage source is supplied. Never reinterpret a revised historical series as proof of what was knowable at the time.
