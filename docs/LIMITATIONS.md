# Limitations and claim boundary

CutoffGuard checks explicit record timestamps, declared availability and label
maturity, split membership, artifact fit windows, and one controlled future
perturbation. It cannot observe undocumented runtime behavior, opaque vendor
transformations, network calls, model weights, or hidden feature-generation
code.

The run-manifest audit is therefore a declaration-level conformance check. A
clean result means that no implemented failure was demonstrated under the
provided declaration. It is not a proof of zero leakage, historical-vintage
truth, model validity, investment performance, or production safety.

Examples are synthetic and offline. Any availability schedule added to a
macro-data demonstration must be labelled as an assumption unless an
authoritative historical-vintage source is supplied.
